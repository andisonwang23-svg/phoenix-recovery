mechanical and wiring problems before voltage is applied.

## Mechanical restraint

| Check | Pass | Notes |
| --- | --- | --- |
| Battery sits in a tray, cradle, or fixed holder |  |  |
| Strap or door prevents battery from lifting out |  |  |
| Hard stops prevent forward and backward sliding |  |  |
| Battery lead has strain relief |  |  |
| Battery can be removed without pulling on the pouch |  |  |
| No screw tip, sharp print edge, metal part, or carbon fiber touches the battery |  |  |
| Servo arms cannot hit the battery |  |  |
| Parafoil lines cannot rub the battery or battery wires |  |  |
| Smooth battery cover is installed if nearby parts could touch the pouch |  |  |

## Wiring inspection

| Check | Pass | Notes |
| --- | --- | --- |
| Battery positive goes only to the intended power input |  |  |
| Battery ground goes to the intended ground bus |  |  |
| UBEC output positive goes to the 5 V rail |  |  |
| Servo power comes from the UBEC, not the ESP32 3.3 V rail |  |  |
| Servo ground and ESP32 ground are common |  |  |
| Sensor wires are not pinched or pulled tight |  |  |
| GNSS antenna and cable are not crushed or shorted |  |  |
